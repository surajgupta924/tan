# Tansur Software Solutions - Enterprise Web Platform

Official website and software ERP portal for **Tansur Software Solutions**.

## 🚀 Key Features

- **Built with Next.js 15 & Turbopack**: Ultra-fast SSR & SSG architecture.
- **Tailwind CSS Styling**: Modern, clean design with customized glassmorphism and high-contrast layouts.
- **Multiple Dedicated Pages**:
  - `Services`: Master Interactive Explorer Studio covering all 8 official services.
  - `Products`: Turnkey SaaS & ERP products (Society Management, Biometric Payroll, School ERP, Travel Engine).
  - `Hire Developers`: Staff augmentation platform with 48h onboarding roster.
  - `Our Works`: Proven client case studies with verified KPI metrics.
  - `About`: Company vision, authentic in-house engineering team showcase & campus infrastructure.
  - `Blog`: Technical guides, ERP innovations, and payroll compliance articles.
  - `Contact`: Interactive project intake form with Google Maps location and instant WhatsApp redirection.
- **Secure Admin Panel (`/admin/dashboard`)**:
  - Master Aside Sidebar Navigation (3 Pages).
  - **Relational DataTable** for all contact leads & live demo requests with real-time search & direct WhatsApp button.
  - **Dynamic Products Manager**: Add & remove products live on the website.
  - **Hire Developers Manager**: Add & remove developer profiles live.
- **MongoDB Database**: Integrated with Mongoose models for reliable lead capturing and product cataloging.
- **100% Pro-Level SEO**: Schema.org JSON-LD Structured Data, dynamic `sitemap.xml`, `robots.txt`, OpenGraph & Twitter meta tags.

## 🛠️ Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open in browser:
   - Public Website: [http://localhost:3000](http://localhost:3000)
   - Admin Login: [http://localhost:3000/admin/login](http://localhost:3000/admin/login) *(Password: `admin@tansur2025`)*

## 📦 Production Build

```bash
npm run build
npm start
```
